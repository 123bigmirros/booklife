# iPad 横屏功能介绍

[在项目首页播放](https://123bigmirros.github.io/booklife/#demo) · [下载 MP4](media/booklife-ipad-intro.mp4)

短片约 34 秒，使用 iPad 模拟器录制。画面保留完整的横屏应用窗口，底部是中文字幕，无配音。

| 时间 | 画面 |
| --- | --- |
| 00:00 | 从书库打开原创示例 EPUB《留一点时间，给阅读》 |
| 00:06 | 打开 Apple Pencil 工具，查看画笔颜色与粗细 |
| 00:10 | 在原创 PDF《阅读札记》中选中文字，调出翻译与笔记菜单 |
| 00:15 | 从正文打开阅读脉络，再展开关系图 |
| 00:20 | 在「林川」节点写下「旧书店是故事的起点。」 |
| 00:25 | 查看林川与旧书店的「初次相遇」连接 |
| 00:29 | 在同一节点切到 AI 提问界面 |

演示使用独立临时书库。人物和关系均为虚构示例，录制期间使用本机数据，AI 镜头展示提问入口。
