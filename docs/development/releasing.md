# 开源与发行清单

## 源码发布

1. 运行 `python3 scripts/generate_project.py`，确认重生成结果可复现，且项目未包含同步冲突副本。
2. 运行 `bash scripts/check.sh` 与 iPad 托管测试。优先检查 11 英寸 iPad Pro 横屏，再验证竖屏、窄窗口、大字体及其他尺寸。
3. 运行 `python3 scripts/check-publication.py`，再导出到全新的目录：`python3 scripts/check-publication.py --export build/public-source`。从该目录创建公共仓库，不上传整个工作目录。
4. 人工核对导出目录：只应有 `Apps/`、`Sources/`、`Tests/`、工程、构建配置、公开文档、许可证、原创示例与有许可证的第三方资源。不能包含 `build/`、本地归档、个人书籍、笔记、API Key、设备标识、安装记录和截图日志。导出后在另一目录验证构建；验证产生的缓存与日志也不应上传。
5. 若使用已有 Git 仓库，审计所有分支/tag 的历史和远端内容。`.gitignore` 不能清除历史；发现真实凭据先撤销/轮换，再处理历史。当前文件检查通过不能替代这一步。
6. 在托管仓库启用私密漏洞报告和可用的 secret scanning / push protection；配置默认分支保护及 CI 必须通过。先私有验证，再转为公开。
7. 检查 README 下载状态、版本号和文档链接。项目 MIT 授权不改变第三方原许可证。

## iPad 产品验收

- 首次启动可试读；导入、重复导入、错误文件、离线重开都给出清晰结果。
- 侧栏在竖屏与窄窗口可发现；搜索无结果后可恢复，隐藏图书可找回。
- 滚动/分页、目录与搜索跳转、返回上个位置、书签、主题与排版调整保持位置稳定。
- 笔记与原文并行；横屏左右、竖屏上下；键盘不遮挡输入和发送，关闭后可恢复草稿。已有笔记时强制退出并重新打开，再重复输入、自动保存、旋转和阅读菜单操作。
- 事物与关系、跨书查找、导出、删除恢复可完成；保存失败时不丢内容。
- Pencil 与手指输入互不冲突；排版变化可回看原页。Pencil Pro 双击/侧捏必须真机验证。
- VoiceOver、较大文字、减少动态效果、外接键盘及 iPad 分屏要分别手动验收。
- 蓝牙、断线恢复、前后台、休眠、长时间使用和耗电需在实体 iPad/Watch 验收。

## 正式安装包

源码开源与面向普通用户分发安装包是两次发布。正式发行还需自己的 Bundle ID/签名、发行渠道、权限用途与隐私资料、实际使用 API 的隐私清单检查、崩溃与迁移验收。不要把 ad-hoc 构建宣传为已公证或已上架。
