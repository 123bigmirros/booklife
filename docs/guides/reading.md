# 书籍人生 — 舒适阅读，手腕遥控

在 Mac、iPhone 或 iPad 上阅读 EPUB 和 PDF。阅读 Mac 或 iPad 时，可以用 Apple Watch 轻点或转动表冠继续阅读；也可以直接用触控、鼠标和键盘。

当前版本：**0.5.0 · 开发预览**。本指南以 iPad 为主要阅读端；Mac / iPhone 保留兼容能力。iPad 可从已配对的 Mac 书籍人生按需下载图书，Apple Watch 可直接通过蓝牙遥控 iPad 或 Mac。

iPad 顶部以「阅读」「书库」「笔记」为主要入口。首页聚焦正在读的书和最近的想法，书架不重复展示这本书。书库支持搜索、排序及网格／列表切换；右上角书库选项中的「只看已下载」筛选离线图书，设备功能也从书库选项进入。

iPad 阅读时轻点正文切换工具显示；页边点按不翻页，分页模式仅明确的横向轻扫翻页，左上角返回书库，底部工具条提供进度、Pencil、笔记和阅读菜单。滚动或翻页后工具收起，轻点正文可再次显示；选择操作时不会因倒计时突然消失。打开菜单、使用画笔或 VoiceOver 时保留所需控件。横屏连续滚动将正文居中为适合阅读的行宽；页边留白仍可调整，设为零则铺满可用宽度。编辑笔记时收起原文上的工具条，保留原文和输入空间。

## 开始阅读

1. 打开书籍人生，点「试读示例」，或「导入书籍」选择 EPUB 或 PDF。
2. 默认上下滚动；轻点手机正文显示工具。目录、书签、搜索和阅读外观都在阅读工具中。
3. 下次从书库的「继续阅读」回到原位置。可按书名或作者搜索图书。

PDF 和 EPUB 共用选文高亮、下划线、摘录、笔记、添加节点和 AI 对话。选文位置保存在同一本书里，切换 PDF 原版页面与文字重排后仍可返回同一段。原版页面支持滚动、翻页、缩放、留白和 Pencil 手写。重排按原书页组织，支持字体、字号及行距调整，从画笔入口可回到原页继续手写。扫描版可在「主题与排版」里点「识别扫描文字」，让识别出的文字可以搜索、选中和批注。识别副本和读书笔记保存在本机。触屏设备上轻点底部页码可打开阅读工具。

## iPad 结构图

章节、摘录、手写和自己的想法都在同一张图里。长按节点（或用鼠标右键点按）打开菜单。点「添加」会在当前节点下新建子节点，直接输入即可。点「连线」，再点另一个节点并填写连接名称。拖动节点可以调整顺序或改挂到其他分支。

点开节点，卡片内有三个标签。「笔记」用来写想法、看摘录，「连接」列出相连的节点，点一条可查看或编辑关系，「AI」可以围绕这个节点提问或继续上次的对话。切换标签时会保存刚写的笔记。点标题右侧的收起按钮即可回到紧凑视图。

搜索支持笔记内容、人物名称及别名、AI 消息、未发送问题、引用原文和连接名称。阅读旁的笔记区提供独立搜索面板，输入时保留原编辑内容，选择结果后再打开；取消搜索回到原来的笔记。开启「跨书查找」可选择其他图书和节点，消息结果会定位到讨论中的那条消息。编辑笔记时用返回按钮回到本章脉络，顶部可直接新建笔记；「草稿与最近删除」位于笔记区的工具菜单中。

iPad 阅读时，统一笔记工作区停靠在原文旁边；横屏左右并排，竖屏与窄窗口上下排列，原文保持可见、可翻动。阅读工具常驻「添加本小节笔记」，面板直接显示补充笔记输入框，直接展示全书脉络，不再区分本节视图。结构图默认占据主要高度；iPad 点击节点后原位展开内容，相邻分支自动排开，收起后恢复紧凑卡片。阅读笔记使用同一张图展示章节、笔记、人物和关系，人物直接连到相关笔记，关系连线保留方向与名称。切换图书回到书库；有删除记录或未完成草稿时，阅读菜单才显示相应恢复入口。节点展开后在上方编辑正文，原文摘录直接显示在下面，修改会自动保存；搜索按需展开。结构卡片直接显示节点内容，长文收起时只显示前几行；连线保留它们与所属小节的关系；全书脉络支持搜索、平移和缩放。Mac 使用同一个工作区，快捷键为 ⇧⌘N。图中可导出当前记录或搜索结果，保留书名、作者、章节、摘录与想法；iPad 文字记录保存为 Markdown，含手写时会打包 Markdown 和图片为 ZIP。Mac 默认保存到下载文件夹，手写图片随附在素材文件夹中。

## 高亮与笔记

选中文字后，在原生菜单选择「问 AI」，直接打开独立讨论面板。选段会显示在面板顶部，可立即提问，无需先创建笔记或打开结构图。支持流式回答、停止和重试；有价值的回答可点「存为笔记」。仅打开后关闭不会创建空笔记，输入的问题和对话自动保存在本机，重新选中同一段原文可继续讨论。笔记编辑区的「AI 对话」保留为另一个入口。对话可在全书脉络、跨书搜索和 Markdown 导出中回看，删除和恢复关联记录也会保留对话。

iPad 是讨论体验的主要交付端：选文讨论有独立面板，横屏与原文并排，竖屏和窄窗口上下排列。面板保持选段明确可见，对话历史独立滚动，输入区与发送／停止按钮固定在底部，并随键盘避让。讨论区显示轻量的自动保存状态，无需手动点击保存。新回答自动跟随，手动回看历史后可点「最新回答」回到底部；外接键盘支持 ⌘↩ 发送。上下文和每条回答依据按需展开；从笔记中打开讨论时，仍可随时展开结构图。

在 iPad 结构图中，选中根节点、章节、笔记、手写或事物节点，可从节点工具条点「问 AI」开启对话。讨论随原节点保存。全书和各章的讨论可在对应卡片中继续，也可搜索或导出。全书和章节使用已读正文抽样及相关笔记，发送前可展开「本次讨论的上下文」检查具体材料。

选文也可从同一个菜单打开「翻译」，选择目标语言后开始翻译。iPad 上较宽的面板将原文与译文并排，较窄的面板将两者上下排列。长选文会分段处理，翻译只发送所选原文。

对话和翻译都优先使用 Codex Luna（`gpt-6-luna`）。Luna 在输出前连接失败或服务暂不可用时，才使用「AI 设置」中配置的备用 DeepSeek（`deepseek-flash`）。回答会标明实际服务，连接中断后的部分回答会保留。Mac 默认使用已登录的 Codex CLI。iPhone 和 iPad 真机在「AI 设置」中填写 Mac 的 HTTPS 桥接地址和令牌。密钥、令牌都保存在本机钥匙串。 [桥接设置](../../scripts/README.md)

讨论会保留本次采用的材料。选文最多带入 8000 字，选文前的附近正文最多 3000 字，自己的想法最多 2000 字，相关已读笔记最多 3 条，每条最多 1200 字。可关闭附近正文和相关笔记。最近至多 7 轮完整对话会作为后续提问的上下文，较早轮次省略时会保留最初问题。

iPad 选中文字后，直接在选文菜单点「写笔记」。如果选段已有笔记，同一位置会显示「编辑笔记」。iPhone 可在系统选文菜单中操作，Mac 可选中文字后点右键。菜单也提供五色高亮和下划线。添加或编辑笔记直接在统一工作区聚焦对应节点及图旁的编辑区，原文范围和章节位置一起带入。可直接关联或新建人物、知识点，补充关系；根据内容中的名称或别名推荐已有卡片，并带出相关旧笔记供对照。关联由自己点选确认，笔记与关系一起保存；未完成内容随草稿保留。章节旁的加号可写章节笔记。

脉络顶部与「写笔记」并列的「事物与关系」提供独立整理入口；正文旁的笔记工具栏也有同名图标。人物扩展为通用事物，支持人物、组织、地点、物品、事件、概念及其他事物。旧人物和知识点保留原 ID、别名与已有链接，知识点归入概念；卡片可修改类型。

在阅读笔记的「添加 → 记录关系」中，按「起点 → 关系名称 → 终点」直接记录，例如「林川 → 加入 → 云山书院」「云山书院 → 位于 → 临江」。两端支持按名称或别名搜索、就地新建，可交换方向；常用关系提供快捷填入，也可自由输入。无需先写笔记，原文依据可后补；主动保存的关系不会因移除依据而消失。关系和事物可分别浏览，支持关键词与类型筛选，默认遵循最远已读范围。事物和关系可移除、恢复；未完成的关系会保留为本机草稿。

这一交互借鉴 [Wikidata 的事物、关系与可选依据](https://www.wikidata.org/wiki/Help:Statements)，以及 [Obsidian 通过链接形成知识网络](https://help.obsidian.md/links)的方式，继续使用本机书库索引保存。

不选中文字时，也可以在阅读工具中选择「随手记」，直接在笔记系统记录当前章节的想法。

纯划线在图中收纳为摘录组，点开查看原句。「回顾已读」在同一工作区汇集已读记录。人物详情、依据与回顾默认遵循历史最远已读进度；回翻前文不会隐藏自己后来写过的笔记。旧书库结合现有记录恢复已读范围，显示范围菜单可显式展开全部记录。已移除「留下疑问」及疑问分类、回应操作；旧疑问与回应的数据继续保留，可作为普通笔记查看。

笔记直接填写想法，不再要求或提供标题输入、在原处展开原文，并关联人物或知识点。关联两项后，可补充如「林川 → 师父 → 沈砚」的关系，或标记为自己的推测。点击关系连线可查看支持它的笔记与引文。人物卡支持别名，避免同一人物用不同称呼重复建立。

连续输入时合并草稿保存，停笔约 0.65 秒后保留到本机；收起或切换笔记时立即保留最新内容。结构索引按数据变化更新，输入每个字时不再同步重建。编辑中的文字与关系会保留为本机草稿，点「保存笔记」或「保存关系」完成提交。脉络界面的「草稿与最近删除」可继续未完成内容或恢复已删除笔记；「继续关系草稿」恢复未完成的关系。点按正文中的已有标记仍可改色、编辑笔记或移除标记。返回阅读会保留原来的阅读位置。

标记使用 EPUB 文字范围定位，调整字号、主题、阅读模式或重新打开图书后会恢复。高亮与笔记保存在本机书库索引及其备份中，暂不参与跨设备进度同步，也不会写入原始 EPUB 或 Apple 图书。

iPad 连续滚动正文延伸至屏幕上下边缘，文字从底边进入，不为浮动工具或底部安全区域预留固定空白；章节之间也不重复添加上下内边距。结构图浏览章节时占满侧栏，点章节节点直接在正文中阅读，节点旁的加号用于添加笔记；只有编辑笔记、节点或讨论时才显示对应编辑区，不再另列章节说明和跳转文字。iPadOS 26 及以上使用系统原生 Liquid Glass；较旧系统使用轻薄材质。目录、搜索、主题排版、书签、手写和脉络笔记集中在同一个浮层内；点位置胶囊调整进度，跳转后可从左上角回到刚才。未完成笔记和手写原页入口收纳在菜单中。搜索输入即查，书签移除可撤销，随手记自动保留草稿；重置排版保留主题与翻页／滚动方式。

## Apple Pencil 书页手写

iPad 打开正文后，Apple Pencil 默认用于阅读和翻页。打开画笔面板并选择笔或荧光笔后，即可直接写字、圈画；选择「阅读」可切回翻页。笔迹画布与 EPUB 正文共用同一阅读视口；手指仍可滑动阅读、翻页、选中文字和打开链接。铅笔按钮只显示或收起与阅读菜单一致的玻璃画笔面板，不再打开独立画图页。落笔期间暂缓页面移动，抬笔后恢复阅读操作。

玻璃画笔面板明确提供「笔」「橡皮擦」「阅读」三个模式。「阅读」让 Pencil 像手指一样滑动、翻页；短暂按住选中词语，保持接触拖动可扩展选区；抬笔立即自动保存高亮，并弹出改色、添加笔记、移除标记和拷贝等选项。无需再点一次高亮，关闭选项也会保留标记。拖动时优先处理笔尖最新位置，避免旧位置排队造成选区追赶；起止点按字符实际边界选取，支持回拖缩小、反向和跨行，抬笔位置也计入最终范围。重复选中已有标记保留原颜色、笔记与未完成草稿；手指选字仍通过原生菜单选择操作。切到阅读前先保存笔迹；保存失败时保留原模式和可编辑画布，切回笔或橡皮擦后继续编辑原来的笔迹。「更多」中保留荧光笔、套索、撤销／重做；笔模式支持颜色和粗细。收起面板会保留当前模式。手指长按选字后，在同一个系统文字菜单中选择高亮颜色、下划线、笔记或 AI 翻译，也可以拷贝和查询。选字时画笔面板暂时隐藏，不再叠加 HTML 高亮面板或系统画笔条。笔迹自动保存，翻页、跳转、调整排版和返回书库前会先提交当前笔迹；返回原位置可继续编辑。保存失败时保留可编辑草稿与当前画布，并阻止丢失笔迹的跳转。连续滚动后继续书写时，记录范围随可见区域扩展，避免裁掉新笔迹。

Pencil Pro 使用笔身快捷操作：双击在笔与橡皮擦间切换，再次双击恢复原笔型、颜色和粗细；侧捏一下进入阅读，再侧捏恢复原来的书写工具。在阅读模式双击也可恢复书写。切换不打开工具面板，只短暂显示当前模式。侧捏只在松开时执行一次；落笔中收到的动作在抬笔后执行，保留动作来源。切到阅读前先保存笔迹，保存失败则留在原模式。系统禁用手势或指定运行快捷指令时，应用不接管。颜色、粗细和更多工具通过底部工具条的 Pencil 入口设置。

正文不再限制为固定 880 点宽；左右留白由「主题与排版 → 排版细节 → 页边留白」控制，调到 0 后滚动和翻页模式均使用完整窗口宽度。

手写与章节、摘录、人物和知识点继续共用「全书脉络与笔记」。圈画会按原文位置组成手写节点，同时呈现原文摘录与局部笔迹；同一段连续圈画和明确相邻的批注可归在一起，相距较远或归属不明确的内容分别保留。已有分组在继续书写时保持稳定；相同原文在不同排版下的标记可保留在同一个节点中，各自保存原始笔迹与排版。

点击手写节点展开卡片，可在书页预览下方点「查看原文」跳转到对应章节。点「写笔记」可在标记下方输入文字，点「完成」后收起编辑框。卡片内也可以定位原文和关联事物。展开「关联事物」可以搜索或新建人物、地点等节点，勾选表示已关联。长按手写节点或展开后的笔迹预览，点「合并」，再点另一个手写节点，就能把两组放在一起。含多处标记的节点可直接点「拆分」恢复各处标记。合并、拆分、删除均可在画布上撤销或重做，关联和文字随记录保留。导出包含各处标记的摘录、文字与图片。长按后也可直接点「问 AI」或「删除」。点预览下方的「回原文书写」可继续批注，未完成的草稿会优先恢复。iPhone 可从「更多 → 显示画笔工具」选择画笔，启用手指书写，收起工具后继续阅读。

EPUB 会随字号和窗口重新排版。笔迹在原来的排版、主题和窗口尺寸下随原文显示；如果排版不同，原文锚点处会提示「此处有手写批注 → 查看原页」，避免把圈画叠到其他文字上。原页截图只用于回看和导出；正文阅读与落笔使用实时 EPUB。笔迹、原页和预览分别保存在本机书库的 `PageNotes/` 中，原有记录和备份兼容，手写暂不跨设备同步。

## 在 iPad 获取 Mac 的书籍

1. 两台设备连接同一 Wi-Fi，Mac 打开书籍人生。
2. iPad 侧栏底部「连接与同步 → Mac 书库」，选择这台电脑。首次在 Mac「手表遥控 → 连接新设备」核对数字并允许连接。
3. 书目自动显示，点封面下载并阅读。下拉刷新书库；右上角书库选项的「只看已下载」可查看本机图书。

获取目录和下载新书时需要 Mac 在线；已下载的书可以独立阅读。手表直接蓝牙控制 iPad，不需要 Mac 或 iPhone 中转。这里的书籍来源是 Mac 书籍人生，包含它能够读取的 Apple Books EPUB 和 PDF；没有直接访问 iPad 苹果「图书」的私有目录。

## 用 Apple Watch 阅读

1. 在 iPad 或 Mac 的书籍人生打开「手表遥控」。
2. 打开手表书籍人生，直接点设备名称。附近设备自动显示在前面。
3. 首次核对两端数字，在阅读设备允许连接。
4. 打开一本书，轻点手表或转动表冠阅读。

以后自动连接上次选择的设备；阅读时轻点手表顶部设备名即可换到另一台。Mac 与 iPad 分别记住，切换不用重新配对，也不需要选择连接方式。

iPad 需保持阅读页面前台亮屏，Mac 需保持唤醒和阅读窗口打开。终端仍通过 Mac 书籍人生接收连接。支持的手表可在唤醒后双指互点；断线后不补发旧操作。详见 [连接说明](connections.md) 和 [iPad 阅读](reading.md)。

## 书库与同步

- 图书离线保存在本机，重复导入同一文件会复用原书并保留进度和书签。
- 「从书库隐藏」保留本机文件和阅读记录；在书库「更多 → 恢复隐藏图书」找回。
- 手机下载的 Mac 图书可单独「移除下载，保留阅读记录」，连接原 Mac 后可重新下载。
- 阅读进度默认保存在本机。跨设备同步可在「阅读进度同步」选择 iCloud Drive 中的同一个文件夹；无需安装其他应用，也没有目录名称限制。
- 已配对的手机也会与 Mac 自动交换位置，并可下载 Mac 的书籍。阅读中收到新位置会先提示，不会突然跳页。书签仍只保存在本机。
- 旧版本的已用同步目录自动迁移保留；新安装默认不连接个人目录。详见 [进度同步](progress-sync.md)。

Mac 本机书库位于 `~/Library/Application Support/BookSlide/Library/`，包含图书副本、书签和位置。索引保存时保留上一份可读备份；读取失败时尝试恢复。备份不能代替完整的系统备份。

当前局域网传书和进度交换使用签名 HTTP，配对凭据单独加密；书籍流量尚未全程加密，请仅在可信局域网使用。公开分发前仍需完成正式签名、隐私及实体设备验收。

## 系统与安装

- Mac：macOS 13+。
- iPhone / iPad：iOS / iPadOS 17+。
- Apple Watch：watchOS 10+；原生双指互点还需支持的硬件和系统。

当前仓库提供开发构建，尚无正式对外下载渠道。本地构建签名不等于 Developer ID 公证，也不等于 TestFlight 已发布。

终端用户可以运行 `bookslide`，详见 [终端阅读器](terminal.md)。

## 开发与验证

打开 `booklife.xcodeproj`，选择 `booklifeMac`、`booklifePhone` 或 `booklifeWatch`。手机和手表需配置自己的开发者 Team。

```bash
python3 scripts/generate_project.py

xcrun swift scripts/checks/reader-annotations-check.swift

/tmp/bookslide-native-menu-check
xcrun swiftc -parse-as-library Sources/BookSlideCore/ReaderPageNote.swift Sources/BookSlideMac/Notes/ReaderPageNoteSchemeHandler.swift scripts/checks/reader-page-notes-check.swift -o /tmp/bookslide-page-notes-check
/tmp/bookslide-page-notes-check
bash scripts/check-simulator.sh
```

模拟器检查复用本机共享 iPad，先运行 PencilKit／WebKit 测试，再运行界面测试；手写界面测试使用前一步从真实 EPUB 生成的隔离书库夹具。构建缓存和测试产物保留在项目目录之外。

代码分为 `BookSlideCore`、`BookSlideTransport`、Mac / Phone / Watch 界面和终端模块。离线阅读引擎及许可证在 `Sources/BookSlideMac/Resources/Reader/`；包含 epub.js、JSZip 和中文字体资源。

测试通过不代表真机连接、休眠恢复和耗电已完成验收。开发与发行验收见 [架构与验证](../development/architecture.md) 和 [发布清单](../development/releasing.md)。个人设备安装记录不包含在公开源码中。
