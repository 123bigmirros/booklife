# 连接与配对

Apple Watch 通过蓝牙直接连接 iPad 或 Mac。默认使用上次选中的阅读设备；Mac 传书、进度同步和手表遥控分别管理。

## 首次连接

1. 在 iPad 或 Mac 打开书籍人生的「手表遥控」，选择「连接新设备」。
2. 手表打开书籍人生，在附近设备中点选这台阅读设备。
3. 核对两端六位数字，在阅读设备允许连接。
4. 打开一本书，手表轻点或转动表冠即可阅读。之后会自动恢复已保存的连接。

iPad 需保持阅读页面前台亮屏；Mac 需保持唤醒、阅读窗口打开且未最小化。换设备时在手表选择目标；首次连接另一设备仍须批准配对。关闭接收会使当前遥控会话失效。

## 失败与恢复

- 找不到设备：检查蓝牙权限、距离、接收是否暂停，并在阅读设备重新打开配对窗口。
- 可以连接但无法翻页：检查是否已打开图书、阅读器是否前台可用、是否仍在排版或书写。
- 断开后保留选定设备并继续发现，不把操作自动转到其他设备，也不在重连后补发旧指令。
- 表冠在滚动模式发送小步位移，分页模式保持页级操作；回执与阅读器的当前会话对应。
- 支持的 Watch 可在唤醒时双指互点。真机前后台、休眠恢复、距离与耗电需单独验收。

## Mac 书库与网络

iPad 获取 Mac 书籍时，两台设备需在同一可信局域网，Mac 书籍人生保持在线。它与手表直接蓝牙链路独立；已下载书籍可离线阅读。

局域网接口使用签名请求与响应，配对凭据加密交换并保存在 Keychain。图书流量目前没有全程加密，不能向公网暴露接收端口。详见 [安全与隐私](../../SECURITY.md)、[架构与验证](../development/architecture.md)。
