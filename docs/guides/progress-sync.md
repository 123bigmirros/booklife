# 阅读进度同步

## 使用

默认自动保存本机进度，不需要账号或额外应用。

跨设备同步时，在 Mac、iPhone 或 iPad 的「阅读进度同步 → 选择同步文件夹」选择 iCloud Drive 中的同一个文件夹。文件夹可以自行命名。这里只写入 `BookSlideProgress-v1` 子目录，不修改其他文件。

已开启后，可「检查同步」，或在「管理」中更换文件夹、关闭文件夹同步。关闭只停止该通道，不删除本机或共享目录中的记录；已配对手机与 Mac 的局域网交换仍可使用。

书籍需要在各设备导入，或通过手机从 Mac 下载相同版本；书签只保存在本机。打开书籍后延续已同步到本机的位置，阅读中收到其他设备位置会先询问，避免突然跳页。终端共用 Mac 配置，按 `u` 继续共享位置，按 `s` 检查。

离线记录保留；应用运行时定期检查，iCloud 的实际上传与下载由系统安排，不保证即时送达。界面上的「文件已交换」不代表另一台设备已经收到。

## 升级兼容

已有本机进度的 Mac 安装会将旧版默认文件夹迁移为持久授权；已选目录的手机继续使用原授权。新安装不自动选择旧版个人目录。迁移只做一次；关闭同步后不会因重启而重新连接。原有进度格式、内容锚点和书籍身份不变。

若旧目录不可访问，可直接选择新的共享目录；本机进度不受影响。

## 实现

OPF 清单 SHA-256 用于辨认同一版本的书。图形阅读器存储 EPUB CFI、章节路径、规范化短文本片段和章内比例；终端使用同一内容锚点。全书百分比按可阅读章节等权估算，并非按字数计算。

每个阅读来源对每本书单独记录，使用文件协调与原子写入。按时间和记录 ID 合并，允许主动回看；被动恢复、换字号不产生新的阅读动作。同步记录包含定位用短文本片段、设备来源和更新时间，不包含整本书。

本机目录：`~/Library/Application Support/BookSlide/Progress/`。通过系统文件选择器保留目录授权；不依赖 CloudKit 容器。库中的旧个人路径仅用于一次性迁移，不再用于默认同步或用户引导。

## 验证

`ReadingProgressTests` 覆盖双向交换、任意目录名、更换和关闭目录、旧版迁移、新安装不自动加入、关闭后不重新加入，以及本机记录保留。

`reader-progress-check.swift` 验证真实 WebKit 的 CFI、锚点及被动恢复。隔离目录测试不代替外网 iCloud 多设备实测。
